# 视觉标识 / Visual identity

## 中文

- `icon.svg`：仓库的原始 SVG 标识，128 × 128 视口，可无损缩放。空间框架表示工程结构，蓝色轨迹表示观察和运动，铜色节点表示探索焦点。
- `motor-preview.svg`：目录页使用的电机横截面示意插图，并非三维仿真的截图或场强结果。
- README 与站点使用同一标识；目录以相对路径引用，Motor Lab 构建时内嵌为 data URI，以保持单文件离线运行。
- 原始图形使用仓库 MIT 许可。可以复制 SVG 作为其他演示或文档的标识，但请保持长宽比和小尺寸下的可读性。
- GitHub 仓库没有独立头像上传功能。本标识通过 README 识别项目；它不代表更改 CZL-Homelab 的组织头像。

## English

- `icon.svg` is the original repository emblem with a scalable 128 × 128 viewBox. The spatial frame represents engineering structure, the blue orbit represents observation and motion, and the copper node marks a point of exploration.
- `motor-preview.svg` is a schematic cross-section for the project directory, not a simulation screenshot or field-strength result.
- The README and website share this identity. The directory references it relatively; Motor Lab embeds it as a data URI to preserve standalone offline operation.
- Original graphics use the repository's MIT license. Reuse the SVG in related demonstrations or documentation while preserving its aspect ratio and small-size readability.
- GitHub does not provide a separate repository-avatar upload setting. This emblem identifies the project in its README and website; it does not change the CZL-Homelab organization avatar.
