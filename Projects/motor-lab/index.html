02 / 电去了哪里？

电源名称不能直接决定效率

没有变成轴功率的部分，主要成为热。

传统小型交流风扇常使用罩极或单相感应电机。转子感应电流、绕组电阻、铁芯损耗，以及不理想的磁场都会消耗能量。永磁无刷电机减少了转子励磁电流带来的损耗，但仍有定子铜耗、铁耗、驱动器损耗和机械损耗。

η = P轴输出 / P电输入
P损耗 = P输入 − P输出

无功功率本身不等于发热。建立磁场所需的无功电流往返交换能量，但这部分电流也流过实际电阻，从而增加 I²R 损耗。

同风量，才好比较。电机效率、扇叶气动效率、驱动器效率是不同环节。温升还取决于散热条件，不能仅凭摸起来热不热推断效率。

03 / 这些名字，不在同一个分类轴上

交流 / 直流：供电与驱动

描述电源或驱动体系。市电 BLDC 风扇先将交流整流，再由电子驱动器给绕组换向。

有刷 / 无刷：换向与接触

BLDC 没有电刷与机械换向器。感应电机也通常没有电刷，但不因此就称为 BLDC。

同步 / 异步：磁场与转速

同步电机稳态时转子与旋转磁场同速；异步电机电动运行需要转差来感应转子电流。

本实验室模型转子磁场来源如何换向 / 造旋转磁场转速关系典型用途与特点

BLDC 与正弦驱动永磁同步电机在结构和控制上有交叠。这里用“六步梯形换相”与“正弦电流驱动”帮助比较，不把名称当成互斥的硬性边界。并非所有电脑风扇都是三相六步驱动；单相、两相无刷方案也很常见。

04 / 把容易混淆的地方说清楚

“无刷”就是没有石墨刷子吗？

对 BLDC 来说，是没有向旋转电枢供电并配合机械换向的电刷和分段换向器。有刷直流电机的电刷是滑动电接点；线圈随转子转，换向器在适当角度反接电流。BLDC 把线圈放在定子，永磁体放在转子，由半导体开关完成换相。电刷也不全是纯石墨，可能含铜等材料。

单相交流电怎么启动电机？

单个绕组形成的脉动磁场可分解成幅值相等、方向相反的旋转磁场，静止时净启动转矩为零。电容运转电机让空间错开的主副绕组电流产生相位差；罩极电机利用短路铜环使部分磁通滞后。实际磁场通常不是理想圆形旋转磁场，反向分量与损耗会随工况改变。

同步为什么仍有“落后角”？

同步指稳态角速度相同，不表示转子磁轴和定子磁场轴始终重合。为了产生转矩，两者存在角度差，称为转矩角或负载角。负载增加时角度通常增大；超过能力可能失步。实验台只模拟可稳定运行的工作区间。

为什么异步电机不能完全追上磁场？

在理想正序基波分析下，转子若与磁场同速，两者相对运动为零，转子感应电动势和电流随之趋零，无法维持电动转矩。电动工况下 s=(nₛ−n)/nₛ；转子铜耗为 sPδ，电磁转换机械功率为 (1−s)Pδ。单相电机有正反向磁场，不能直接用这一条关系概括全部转子损耗。

BLDC 绕组里也有交流，为什么还叫直流电机？

名称通常指直流供电和电子换相的驱动体系。直流母线经过逆变桥后，绕组电流会随位置换向。常见路径是“市电交流 → 整流滤波 → 直流母线 → 逆变驱动 → 电机”。转子跟随电子控制的磁场，因此属于永磁同步机范畴。

转得慢，是不是就一定省电？

在相似工况、相同叶轮和近似恒定空气密度下，风机相似定律给出风量约随转速变化，压升约随转速平方变化，轴功率约随转速立方变化。实际还受风道、控制方式和效率变化影响。降速常能明显减小轴功率，但不能把调压感应电机的损耗与变频 / BLDC 调速混为一谈。

电机发热大，哪些因素可能参与？

绕组 I²R 损耗、铁芯磁滞与涡流、转子感应电流、轴承摩擦、风阻和驱动器损耗。罩极铜环也有损耗。电容衰减、轴承卡滞或堵转可能造成异常温升；允许温度和判断方法应以具体产品资料为准，本网站不提供故障温度阈值。
