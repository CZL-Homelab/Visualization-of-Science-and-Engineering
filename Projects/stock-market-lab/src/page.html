DATA / 数据

默认全离线，也可以导入你自己的历史数据。

课程数据全部由确定性种子生成，标注为“模拟”。你也可以载入本地 CSV 或 JSON 行情文件，在 K 线实验室里检查它，页面不会上传文件。

导入本地行情

支持 CSV 或 JSON。必需列：date（或 time）、open、high、low、close；可选 volume。列名不区分大小写，也接受常见别名（t/o/h/l/c/v）。

尚未导入。课程将使用模拟数据。
或直接粘贴 CSV / JSON

导入后会检查什么

  • 每根 K 线必须满足 low ≤ min(open, close) ≤ max(open, close) ≤ high。
  • 时间为空、无法解析或顺序倒置的行会被报告，可跳过或中止。
  • 缺成交量时按 0 处理，并提示“该数据没有成交量，成交量类指标不可用”。
  • 载入后标明数据来源、时间范围、时区（按本地解释）、币种与复权状态（默认“未说明”）。
  • 模拟数据与导入数据在界面上用不同徽标区分，切换时不会悄悄混用。

实时行情不是本项目的依赖。断网、直接双击 index.html，全部课程仍然可用。

BOUNDARIES / 模型边界

哪些是教学模型，哪些不是。

通用边界

所有价格路径、订单流、IPO 需求与收益分布都是合成数据，用来展示机制，不是预测。撮合器是简化连续竞价模型，不实现交易所全部订单类型、路由与风控。

制度边界

规则表只覆盖常见主板、创业板、科创板与美股常规交易情形。未覆盖的板块、特殊证券、盘前盘后与跨境税务会明确标注“规则介绍，非完整撮合”。

费用边界

佣金、税费、滑点都是可修改的示例费率，不代表任何一家券商。A 股印花税单边征收、美股监管费随年度调整，界面上均可改。

不构成投资建议

本项目用于理解机制。任何数字都不应作为买卖依据；真实交易还涉及适当性、流动性、税务与个人风险承受能力。
