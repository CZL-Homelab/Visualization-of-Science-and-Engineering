# Stock Market Lab — agent and contributor notes

Read the repository root [`AGENTS.md`](../../AGENTS.md) first. This file adds rules specific to
the finance lab. They exist because a plausible-looking chart with a wrong formula is worse than
no chart at all.

## Scope and layout

- `src/` is the source of truth. `index.html` is generated by `python3 build.py` and is committed.
- `src/core.js` is the only place for finance math. Do not re-derive a formula in a module.
- `src/market-rules.js` holds dated rule constants and sources. Never hard-code a limit, fee or
  session time in a module without reading it from here (or clearly labelling it as an example).
- `src/simulations.js` owns the order book, IPO demand, margin paths and Monte Carlo.
- `src/modules/a-basics.js` … `j-compare.js` are teaching modules. Each registers exactly one
  module with `SM.registerModule({ id, slug, order, title, en, subtitle, hint, scenes, quiz, mount })`.
- `src/charts.js`, `src/ui.js` are shared presentation helpers. Extend them instead of copying
  chart or control code into a module.
- `work/` is ignored by git: screenshots, temporary preview builds and one-off checks belong there.

## Non-negotiable editorial rules

- Chinese UI. English technical terms are fine in small caps labels.
- Simulated data must be labelled 模拟 / SIMULATED; a fixed-seed model must say so.
- Never claim a pattern, indicator or model predicts the future. No 必涨 / 必跌 / 稳赚.
- Distinguish: 阳线 vs 当日涨跌幅; 成交量 vs 净买入; 市值 vs 现金; IPO 募资 vs 市值;
  拆股 vs 增发; T+1 回转 vs T+1 交收; 交易所 vs 券商 vs 账户规则.
- Colour must never be the only channel. Pair red/green with signs, labels or numbers.
- Each module must expose its simplifying assumptions (a `ui.warn` or an equivalent block).
- Do not add a “buy/sell signal”, a recommendation, or a hypothetical portfolio presented as advice.

## Rules freshness

- `SM.rules.asOf` is currently `2026-10-31`. When a rule changes, update the constant, the source
  link, the README section, and the affected test in `tests/check-finance.cjs`.
- A-share main-board ST/*ST moved from 5% to 10% on 2026-07-06. Do not restore the old 5% from
  memory. ChiNext/STAR are 20%, BSE 30%, main board 10%; IPOs have no limit for the first five
  sessions on the main board/ChiNext/STAR.
- US settlement is T+1 since 2024-05-28; that is not the same as intraday trading permission.
  LULD bands are 5% / 10% / 20% depending on tier and price; market-wide breakers are 7/13/20%.
- If a fact cannot be verified, write “规则介绍，未在模型中实现” instead of inventing a number.

## Offline and dependency rules

- No CDN, web font, remote image, analytics, API key, backend or npm package. The single
  `index.html` must work from `file://`.
- Icons come from the repository `assets/icon.svg`, inlined at build time.
- `build.py` refuses leftover placeholders and remote `<script src>` / stylesheet links.
- Charts are Canvas 2D + `devicePixelRatio`; the B1 candle editor uses SVG. Keep it dependency-free.

## Interaction and accessibility

- Auto-teaching must pause on any manual control, on visibility change, and at the last scene.
  Manual state must never be overwritten by the director.
- Respect `prefers-reduced-motion`; avoid continuous animation unless it explains a relationship.
- Sliders need units, legal ranges, a numeric input and a reset. Invalid input must explain itself.
- Charts need hover/readout, keyboard access where practical, and a text/DOM summary of the numbers.
- Check 1920×1080, 1366×768 and 390×844 in both themes before claiming a layout works.
- Never use `alert`/`confirm` for teaching feedback; use inline notes or the app toast.

## Theme and navigation

- The shared theme key is `czl-lab-theme`. `src/page.html` sets `data-theme` before first paint;
  `src/app.js` owns `applyTheme`, the button label/icon, `aria-pressed`, `meta[name="theme-color"]`
  and keeps the legacy `sml.theme` key readable during migration.
- Keep `#themeToggle` a native button with a readable label. Charts must redraw on the `sm:theme`
  event; do not cache CSS colors at construction time.
- The header keeps a `Lab Projects` back link (catalog with `#projects`); the pre-footer
  `.lab-directory` lists all labs and marks the current one. Relative links must resolve under the
  Pages subpath and from `file://`.
- When adding a lab, update this directory, the Motor Lab directory and `site/projects.json`.
- Verify both palettes for text contrast, chart grid/axis colors, focus rings and 390px layouts.
  A passing console check is not a visual check.

## Build and verification

```sh
python3 build.py
for f in src/*.js src/modules/*.js; do node --check "$f"; done
node tests/check-finance.cjs
node tests/check-build.cjs
git diff --check
```

- `tests/check-finance.cjs` asserts finance invariants with known values (MA5 = 11.4, IPO dilution,
  fees, 2× leverage loss, maintenance ratio, order priority, …). Add a test when you add a formula.
- `tests/check-build.cjs` asserts the generated page has no remote resources, all ten modules are
  registered, and the required anchors exist.
- Browser checks: `node work/shot.js <url> <w> <h> <out.png> "<js>"` prints console errors and
  saves a screenshot. Use it for each scene and at least one mobile size. A page that “has no
  errors” but renders a blank canvas is still broken — inspect the image.
- CI is `.github/workflows/stock-market-lab.yml`; the Pages workflow builds this project before
  `scripts/build_site.py`. Both must stay green.

## Git and review

- Work on a feature branch; do not reset, force-push or rewrite `main`.
- One module per commit is welcome, but keep `index.html` regenerated in the same commit.
- Do not commit `work/`, screenshots, downloaded data or credentials.
- Preserve the root directory page and the Motor Lab routes; add new demos via
  `site/projects.json` with a `previewAlt`.
