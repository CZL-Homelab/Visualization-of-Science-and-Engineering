# Distillation Lab 协作说明 / Agent and contributor notes

## 中文

- 先读根目录 `AGENTS.md` 和本项目 `README.md`。`src/` 是唯一源码，修改后运行 `python3 build.py`，把生成的 `index.html` 与源码一起提交。
- 热力学与塔计算只放在 `src/thermo.js`（Antoine、活度系数、泡点、闪蒸、Rayleigh、McCabe–Thiele、Rmin、FUG、间歇、水蒸气蒸馏、TBP、操作型计算）；模块只调用它，不在模块里重写公式。`src/plots.js`、`src/column.js` 是共享绘图层，扩展而不是复制。
- 每个物性常数要有来源：新增组分须给出 Antoine 常数及温度范围，对照 NIST WebBook，并在 `tests/check-thermo.cjs` 中保证常压沸点与文献相差 ≤ 0.3 °C。
- 乙醇–水与乙二醇相关二元对使用 Aspen Plus V15（APV150）导出的 NRTL 参数，原始数据在 `src/aspen.js`，`thermo.js` 中的 `NRTL` 必须与之逐位一致（有测试）。`src/aspen.js` 是维护者提供的参考数据，不修改数值；新增导出作为新键，并扩展对照测试与数据表。丙酮–氯仿使用由 1 atm 恒沸点反算的 van Laar；改 Antoine 常数后须重新拟合。
- 本项目是纯科普：不加测验、自测题、提问、评分或学习进度/打卡，讲解标题与提示用陈述句，不向读者设问（`tests/check-build.cjs` 检查模块中没有 quiz）。
- 讲解、提示中引用的数字（级数、温度、组成、比值）必须是模型实际算出的值；改默认值或模型后重新核对。示意部分（操作窗口、成本曲线、原油 TBP、动画）在页面和 README 中标注“示意”；能与 Aspen 对照的数字，直接给出对照而不是免责声明。区分理论级与实际塔板、Murphree 与全塔效率、Rmin 与操作回流比、恒沸物与化合物。
- 自动讲解在手动操作、页面隐藏和最后一幕时暂停，导演不得覆盖手动状态；Canvas 动画在离开视口、页面隐藏和减少动态效果时停止。检查 1440×900 与 390×844 的深浅主题。
- 主题与入场来自仓库公共的 `assets/theme.js`、`entry.js`、`entry.css`，由 `scripts/shared_experience.py` 内嵌（配置键 `distillation-lab`，事件 `distl:theme`）；`app.js` 只调用 `CZLLabTheme.mount()`，不再自写存储或按钮逻辑。页脚前目录列出 `site/projects.json` 中的全部实验室并标记当前页，新增实验室时同步所有目录。
- 验证：`node tests/check-thermo.cjs`、`node tests/check-build.cjs`，对 `src/*.js`、`src/modules/*.js` 执行 `node --check`；仓库根目录运行 `python3 scripts/check_site.py` 与 `git diff --check`。

## English

Read the repository root [`AGENTS.md`](../../AGENTS.md) first. This file adds rules specific to the
distillation lab. They exist because a plausible-looking McCabe–Thiele diagram drawn from a wrong
constant teaches the wrong thing with great confidence.

### Scope and layout

- `src/` is the source of truth. `index.html` is generated by `python3 build.py` and is committed.
- `src/thermo.js` is the only place for thermodynamics and column math (Antoine, activity models,
  bubble points, tie lines and the lever rule (`tieLine`), flash, Rayleigh, McCabe–Thiele, Rmin, Fenske/Underwood/Gilliland, batch, steam
  distillation, TBP). Modules must call it; never re-derive a formula inside a module.
- `src/plots.js` (SVG charts, shared McCabe–Thiele and T–x–y drawings) and `src/column.js`
  (animated column) are shared presentation helpers. Extend them instead of copying drawing code.
- `src/modules/a-vle.js` … `j-compare.js` each register exactly one module with
  `DL.registerModule({ id, slug, order, title, en, subtitle, hint, scenes, mount })`.

### Scientific rules

- Every property constant needs a source. If you add a component, add its Antoine constants with
  their temperature range, check them against NIST WebBook, and extend `tests/check-thermo.cjs`
  (the normal boiling point must match literature within 0.3 °C).
- Activity-model parameters must say how they were obtained. Ethanol–water and the ethylene-glycol
  pairs use NRTL parameters exported from Aspen Plus V15 (APV150); they live in `src/aspen.js`
  and are copied into `thermo.js` `NRTL` — a test requires both to match exactly. Acetone–chloroform
  uses van Laar fitted to its 1 atm azeotrope with `fitVanLaar`; if you change Antoine constants, refit it.
- `src/aspen.js` is reference data supplied by the maintainer from Aspen Plus V15. Do not edit the
  numbers; add new exports as new keys and extend the comparison tests and the data tables.
- Any number quoted in a scene or note (stage counts, temperatures, compositions, ratios)
  must be what the model actually computes. Recompute after changing a default or a model.
- Keep labels honest: illustrative parts (operating window, cost curve, crude TBP, animation) must be
  marked 示意 / qualitative in the UI and README. When a number can be compared with the Aspen data,
  show the comparison rather than a disclaimer.
- Distinguish theoretical stages vs real trays, Murphree vs overall efficiency, Rmin vs operating
  R, azeotrope vs compound, vacuum (lower T) vs throughput.

### Interaction and accessibility

- This is a popular-science lab: no quizzes, self-tests, questions to the reader, scores or progress tracking. Scene
  titles and guides are statements, not prompts to answer; `tests/check-build.cjs` rejects quiz data.
- Auto-teaching pauses on any manual control, on visibility change and at the last scene. Manual
  state must never be overwritten by the director.
- Canvas animations stop off-screen, when the page is hidden and under `prefers-reduced-motion`.
- Sliders show units and a numeric input; every module has a reset.
- Check 1440×900 and 390×844 in both themes. A clean console is not a visual check.

### Theme and navigation

- Theme and entrance are the repository's shared `assets/theme.js` / `entry.js` / `entry.css`,
  inlined by `scripts/shared_experience.py` (`<!-- THEME_BOOT -->` and `<!-- SHARED_EXPERIENCE -->`
  in `src/page.html`; config key `distillation-lab`). `app.js` only calls `CZLLabTheme.mount()`;
  do not re-implement storage or the toggle here. The controller fires `distl:theme`, which canvas
  modules (`column.js`, module H) listen to; SVG charts use CSS variables and recolour without a redraw.
- Header `Lab Projects` link to `../index.html#projects`; the pre-footer `.lab-directory` lists all
  labs and marks this one; `tests/check-build.cjs` checks it against `site/projects.json`. When a lab
  is added, update this directory, the other labs' directories and `site/projects.json`.

### Build and verification

```sh
python3 build.py
for f in src/*.js src/modules/*.js; do node --check "$f"; done
node tests/check-thermo.cjs
node tests/check-build.cjs
```

CI is `.github/workflows/distillation-lab.yml`; the Pages workflow builds this project before
`scripts/build_site.py` copies it to `_site/distillation-lab/`.
