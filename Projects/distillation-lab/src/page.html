导入后会检查什么

  • 每行两个数，0 ≤ x, y ≤ 1；无法解析的行会被报告。
  • 按 x 排序并去重；缺少端点时自动补 (0,0) 与 (1,1)。
  • y(x) 必须单调递增，否则无法反查 x(y)，会拒绝载入并说明原因。
  • 若曲线穿过对角线，会标出恒沸点并提示 xD 不能越过它。
  • 导入数据没有温度信息，因此不画 T–x–y 图，塔板温度显示为空。

BOUNDARIES / 模型边界

哪些是教学模型，哪些不是。

热力学模型

气相按理想气体；液相用 Raoult 定律、NRTL（乙醇 / 水 / 乙二醇，Aspen Plus V15 APV150 参数）或 van Laar（丙酮–氯仿）。乙醇–水在 20–1000 kPa 与 Aspen 的泡点相差 ≤ 0.21 °C；文献报告的约 9 kPa 以下恒沸点消失不能再现。萃取精馏按三元 NRTL 计算，但萃取段溶剂分数视为常数；非均相共沸精馏（液液分相）只画流程。

塔的模型

McCabe–Thiele 采用恒摩尔流、全凝器、部分再沸器计为一级；能量只按平均汽化潜热估算。与 Aspen RadFrac 严格计算对照：苯–甲苯基准塔逐级组成偏差 ≤ 0.025、温度 ≤ 0.6 °C。简捷法用 Fenske–Underwood–Gilliland（Eduljee 拟合）。成本曲线只示意“设备费 vs 能耗”的此消彼长。

动画与水力学

塔板上的气泡、液滴与操作区边界是定性示意，用来表达“漏液—正常—雾沫夹带—液泛”的方向关系；真实边界取决于开孔率、板间距、物性与负荷，需要按厂商资料与关联式核算。

不是设计工具

本页数字用于理解机理，不可直接用于塔设计、安全泄放或操作决策。原油 TBP 曲线为合成示意，不对应任何具体原油或炼厂。
