# Engine Lab · 四冲程发动机原理实验室

用剖面动画、示功图和对照实验把四冲程发动机讲清楚：配气正时、点火提前角、压缩比、汽油 vs 柴油、四缸点火顺序。

## 内容

| 模块 | 覆盖 |
| --- | --- |
| 01 结构拆解 | 活塞与环、连杆与曲轴、气门与弹簧、火花塞、飞轮、水套 |
| 02 四个冲程 | 进压做排逐幕拆解 + 连续循环，含点火时刻与气门叠开 |
| 03 配气正时 | 升程曲线、叠开、IVC/EVC、凸轮轴 2:1 传动 |
| 04 点火正时 | 功率-提前角曲线、爆震区、回火区，可拖提前角 |
| 05 示功图 | P-V 闭合环、压缩段、燃烧竖跳、面积 = 净功 |
| 06 压缩比 | CR 实验台、压缩终了压力与温度、爆震极限、柴油机压燃 |
| 07 汽油 vs 柴油 | 双模型同步对照：进气、点燃方式、理想效率 |
| 08 四缸机 | 单缸空窗、曲柄相位、点火顺序 1-3-4-2、飞轮与平衡 |

8 个模块、39 幕讲解、8 个随堂测验。所有场景可暂停、可拖曲轴角度、可关自动导览。

## 快速开始

需要 Git、Python 3.9+ 和 Node.js 22 LTS；无需 npm 或第三方包。

```sh
cd Projects/engine-lab
python build.py
node tests/check-model.cjs
node tests/check-build.cjs
python -m http.server 8766 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8766/engine-lab/`（仓库根起服务时），或直接双击生成的 `index.html`。

## 离线与主题

构建产物为单文件：图标、样式与全部脚本内嵌，断网可用。主题共用全站 `czl-lab-theme` 偏好（跟随系统、可切换、首帧前应用）。导航与其余两个实验室一致：顶栏返回项目目录，页脚前有实验室目录。

## 模型边界

- 几何与压力为教学模型：γ=1.3 空气标准循环、半正弦气门升程、简化的燃烧/爆震函数。
- 配气相位（IVO 695° / IVC 245° / EVO 475° / EVC 25°）是教学代表值，不是任何真实机型的数据。
- 汽油爆震极限 CR≈13.5、效率 η=1−CR^−0.3 均为建立直觉用，不构成工程计算。

## 代码结构

- `src/core.js` — 纯模型函数（运动学、配气、压力、点火、四缸相位），无 DOM。
- `src/engine-render.js` — 共享 Canvas 渲染器（整机、正时条、P-V、升程曲线、凸轮齿轮、多缸、对比）。
- `src/registry.js` + `src/modules/*.js` — 每文件注册一个模块（场景 + 测验）。
- `src/app.js` — 导览、侧栏、测验、主题与工具分发。
- `tests/` — `check-model.cjs`（26 项模型断言）与 `check-build.cjs`（9 项打包断言）。
