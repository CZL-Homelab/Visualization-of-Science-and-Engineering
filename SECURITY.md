# 安全问题反馈

请勿在公开 Issue 中贴出凭据、个人数据或尚未修复漏洞的可利用细节。

若组织仓库的 Security 页面提供 **Report a vulnerability**，请使用其私密报告入口；否则先联系仓库维护者约定私密沟通方式，再发送敏感细节。普通原理、动画或显示问题请使用问题反馈模板。

请说明受影响版本、复现条件、影响范围及建议修复方式。当前项目为静态教学网页；第三方依赖的安全更新也应验证单文件离线兼容性。

## English — security reporting

Do not post credentials, personal data or exploitable details of unfixed vulnerabilities in public Issues. If the repository Security page offers Report a vulnerability, use that private channel. Otherwise, contact maintainers to agree on a private channel before sharing sensitive details. Ordinary scientific, animation or display bugs belong in the bug-report template.

Include the affected version, reproduction conditions, impact and suggested mitigation. This is a static educational site. Dependency security updates must also preserve the documented offline packaging behavior.
